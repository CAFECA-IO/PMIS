# 工程領域知識庫審閱清單

目前共 **562** 項參考工程分項（跨域去重後 **557** 項）。

本清單由 `src/constant/domain-knowledge.ts` 導出，用於逐域校正。

## 為什麼需要審閱

**污水下水道與水資源回收**一域取自你提供的真實監造報告（第 23 次進度及品質檢討會議
施工報告），已標為 `verified`。**其餘各域標為 `ai-pending-review`** —— 內容是 AI 的
工程領域知識，並未以官方文件逐項查證。

原因是本次環境無法取得權威來源：`WebSearch` 不可用；`web_fetch` 對 PCCES 工項編碼
與水利署網站回傳空內容或逾時；維基百科只有概念性敘述而無工項分類。

用字若有誤，注入提示詞後會讓模型輸出錯的分項名稱 —— 這正是建立知識庫要避免的問題。
建議以手邊的**估驗計價單**或**預算書工項明細**逐域對照。

## 審閱方式

1. 打開 `src/constant/domain-knowledge.ts`，找到該領域的 `workItems`。
2. 對照實際文件：用字不同的改掉、不存在的刪掉、缺漏的補上。
3. 該域全部確認後，把 `provenance` 改為 `"verified"`。
4. 執行 `npm test` —— 會檢查項數下限、域內重複、字元異常。
